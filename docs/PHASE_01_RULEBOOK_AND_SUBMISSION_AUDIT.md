## 3. VIDEO 1-এর Required 240-Second Structure

NASA historical "240 Seconds of Glory" pitch framework:

| Time | Block | Purpose | Core Requirements |
| :--- | :--- | :--- | :--- |
| **0:00–0:45** | **WHO** | Attention + Authenticity | - আমরা কারা?<br>- Team members কারা? (Every team member must be named)<br>- কেন problemটা আমাদের attention পেয়েছে?<br>- Hook কী? |
| **0:45–1:45** | **WHY** | Problem + Empathy | - আসল problem কী?<br>- এটা কার problem?<br>- কেন important?<br>- NASA data/experiments থাকা সত্ত্বেও gap কোথায়?<br>- *Problem sell করতে হবে, solution না।* |
| **1:45–2:45** | **WHAT** | Big Idea / Innovation | - আমাদের proposed solution কী?<br>- কীভাবে problem solve করবে?<br>- Innovation কোথায়?<br>- Interface/workflow কেমন হবে? (FLARE-X concept) |
| **2:45–4:00** | **SO WHAT / NEXT** | Impact + Execution | - আমরা কীভাবে build করব?<br>- কোন NASA datasets ব্যবহার করব?<br>- Technical execution কী?<br>- Impact কী?<br>- Hackathon-এ কী deliver করব?<br>- *Execution credibility দিয়ে working demo gap compensate করতে হবে।* |

## 4. Video 1 Hard Rules

* **Rule 1: Under 240 Seconds.** Over-length হলে extra অংশ consider নাও হতে পারে।
* **Rule 2: Every Team Member Must be Named.** Intro card + spoken name দুটোতেই করা safer।
* **Rule 3: Third-Party Material Must be Credited.** Images, stock assets, icons, music, templates, animations, generated content, external diagrams সব credit করতে হবে।
