# PHASE 01 — Requirements & Scope

## Goal
Freeze what the prototype will and will not do.

## Tasks
1. Gather the currently published Flame in Freefall challenge summary.
   Start from `22_CHALLENGE_BRIEF_FLAME_IN_FREEFALL.md`: Section 1 = challenge requirements,
   Sections 2–10 = adopted design decisions. Check the brief against the official NASA page.
2. Extract explicit requirements.
3. Separate:
   - official published requirements
   - assumptions
   - proposed innovations
4. Define target users:
   - combustion researchers
   - spacecraft fire-safety researchers
   - mission/safety analysts
   - students/research users
5. Define primary prototype scenario.
6. Define explicit non-goals.
7. Create requirement traceability matrix.

## Required Outputs
- docs/REQUIREMENTS.md
- docs/PROBLEM_DEFINITION.md
- docs/NON_GOALS.md
- docs/TRACEABILITY_MATRIX.md
- reports/PHASE_01_REPORT.md
- reports/PHASE_01_VALIDATION.md

## Pass Criteria
- no proposed feature is mislabelled as NASA-required
- problem is narrower than "AI fire dashboard"
- user and decision problem are explicit
- prototype limitations are written
