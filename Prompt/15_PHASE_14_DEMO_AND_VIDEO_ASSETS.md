# PHASE 14 — Demo & Video Assets

## Goal
Prepare a repeatable prescreening/demo presentation.

## Create 3 demo scenarios
1. strong in-domain case
2. near-boundary case
3. clearly out-of-domain case

## Demo must visibly show
- NASA source
- scenario input
- evidence retrieval
- prediction
- experimental envelope
- counterfactual
- source traceability

## Create Video-Ready Assets
- architecture diagram
- dataset map
- agent flow
- model flow
- UI screen captures
- experimental envelope visual
- counterfactual visual
- citation cards

## Important
If prototype results are used in a prescreening video, label them clearly as:
"research prototype"
or
"prototype demonstration"
unless local rules explicitly define otherwise.

## Outputs
- docs/DEMO_SCRIPT.md
- docs/DEMO_SCENARIOS.md
- assets/video/
- reports/DEMO_QA.md

## Pass Criteria
Demo succeeds repeatedly and no illustrative value is presented as validated final result.
